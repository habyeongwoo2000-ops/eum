# 화면 설계서 (Screen Design Spec)

- 연관 문서: `PRD_draft.md`(v0.2), `feature_spec.md`(v0.1)
- 버전: v0.1
- 작성일: 2026-08-13
- 함께 첨부: `wireframes.html` (저해상도 와이어프레임 미리보기)

---

## 1. 정보 구조 (IA)

```
서비스
├── 홈 / 게시판 목록 (SC-01)
│   └── 게시글 상세 (SC-02)
│       └── 댓글(질문) 작성 → AI 답변 스레드
├── D-day 대시보드 (SC-03)
│   └── 퇴사일 입력 → D-day 결과
├── 서류 자가진단 (SC-04)
│   └── 이미지 업로드 → 판별 결과
├── 언어 설정 (전역 헤더 컴포넌트, SC-00)
└── (Should) 관리자 — 검수 대기함 (SC-05)
```

하단 탭바 3개 구조: **홈(게시판) / D-day / 서류확인**. 언어 선택은 모든 화면 상단 헤더에 고정 노출.

## 2. 사용자 플로우

### 플로우 A — 퇴사 후 정보가 필요한 근로자
```
앱 진입(자동 언어 감지) → 홈 게시판에서 "사업장 변경" 관련 공지 확인
→ 게시글 상세에서 요약 읽기 → 궁금한 점 댓글로 질문 → AI 답변(출처 포함) 확인
→ D-day 탭 이동 → 퇴사일 입력 → 신청/구직 마감 D-day 확인
```

### 플로우 B — 부당한 대우를 의심하는 근로자
```
앱 진입 → 서류확인 탭 → 계약서/통지서 사진 업로드
→ AI 판별 결과("가능성 있음" 등) 확인 → 결과 카드 내 "지원센터 상담 연결" 안내 확인
```

### 플로우 C — 처음 오는 사용자(언어 확인)
```
앱 진입 → 기기 언어 자동 감지되어 첫 화면부터 해당 언어로 표시
→ (원하면) 상단 언어 아이콘으로 언어 수동 변경
```

## 3. 공통 컴포넌트

| 컴포넌트 | 설명 | 관련 기능 |
|---|---|---|
| 상단 헤더 | 로고 + 현재 언어 표시/변경 드롭다운 | FT-01 |
| 하단 탭바 | 홈 · D-day · 서류확인 3개 탭, 현재 위치 하이라이트 | 공통 내비게이션 |
| 출처·면책 배너 | AI 응답/판별 결과 하단에 고정 노출되는 문구+출처 뱃지 | FT-11 |
| 로딩 상태 | 스켈레톤 UI(카드 형태 회색 블록) | 전체 데이터 로딩 |
| 빈 상태 | "아직 게시글이 없어요" 등 안내 일러스트+문구 | 게시판/댓글 없음 |
| 에러 상태 | "일시적 오류, 다시 시도해주세요" + 재시도 버튼 | 네트워크/AI 응답 실패 |
| 검수 대기 뱃지(Should) | 댓글 답변에 "확인 중" 라벨 표시 | FT-06 |

## 4. 화면별 상세 설계

### SC-00. 전역 헤더 — 언어 설정
- **목적**: 언어 장벽 제거의 핵심 지점. 조작 없이 기기 언어로 시작하되 언제든 변경 가능.
- **레이아웃(저해상도)**
```
┌─────────────────────────────┐
│ [로고]              [🌐 EN ▾]│   ← 우측 언어 드롭다운
└─────────────────────────────┘
```
- **구성요소**: 로고/서비스명, 언어 아이콘+현재 언어 코드, 드롭다운(국기+언어명 리스트, 감지된 언어 상단 하이라이트)
- **상태**: 감지 성공(자동 선택) / 감지 실패(en 기본) / 사용자 수동 변경(세션 우선 저장)
- **관련 기능**: FT-01

---

### SC-01. 홈 / 게시판 목록
- **목적**: 공식 공지의 요약본을 한눈에 훑어보는 진입 화면
- **레이아웃**
```
┌─────────────────────────────┐
│ 헤더(SC-00)                  │
├─────────────────────────────┤
│ [공지 카드]                   │
│  제목 · 요약 미리보기 2줄       │
│  출처뱃지 · 게시일 · 최종확인일  │
├─────────────────────────────┤
│ [공지 카드] ...               │
├─────────────────────────────┤
│ 하단 탭바: [홈] D-day 서류확인  │
└─────────────────────────────┘
```
- **구성요소**: 공지 카드 리스트(제목/요약/출처뱃지/날짜), (Could) 검색·카테고리 필터, (Could) 스폰서 배너(FT-12, 정보와 시각적으로 분리)
- **상태**: 로딩(스켈레톤 카드 3~4개) / 빈 상태(등록된 공지 없음) / 에러(재시도 버튼)
- **인터랙션**: 카드 탭 → SC-02 이동
- **관련 기능**: FT-02, FT-03

---

### SC-02. 게시글 상세 + 댓글(Q&A)
- **목적**: 요약 정독 + 개인화된 질문/답변으로 이어지는 핵심 화면
- **레이아웃**
```
┌─────────────────────────────┐
│ ← 뒤로   헤더(SC-00)          │
├─────────────────────────────┤
│ 제목                          │
│ 요약 본문(번역됨)               │
│ [출처: 조문/공지번호 · 최종확인일]│
├─────────────────────────────┤
│ 💬 질문하기 [입력창........][전송]│
├─────────────────────────────┤
│ Q. 사용자 질문                 │
│ A. AI 답변                     │
│    [출처 뱃지] [면책 배너]      │
│    (검수대기 시 "확인 중" 라벨)  │
├─────────────────────────────┤
│ Q. 다른 사용자 질문 ...         │
└─────────────────────────────┘
```
- **구성요소**: 원문 요약, 출처/최종확인일 뱃지, 댓글 입력창, Q&A 스레드 카드(질문/AI답변/출처/면책배너/검수상태)
- **상태**: 답변 생성 중(로딩 스피너 "AI가 답변을 작성 중입니다") / 검수 대기(Should) / 답변 완료
- **인터랙션**: 질문 입력 후 전송 → 답변 카드 실시간 추가(또는 배치 처리 안내: "검수 후 게시됩니다")
- **관련 기능**: FT-04, FT-05, FT-06, FT-11

---

### SC-03. D-day 대시보드
- **목적**: 기한을 숫자로 명확히 인지시키는 화면 — 이 서비스의 "각인 포인트"
- **레이아웃**
```
┌─────────────────────────────┐
│ 헤더(SC-00)                  │
├─────────────────────────────┤
│ 퇴사일을 입력하세요             │
│ [날짜 선택 필드]  [계산하기]     │
├─────────────────────────────┤
│ ┌───────────┐ ┌───────────┐ │
│ │ 신청 마감    │ │ 구직 마감    │ │
│ │  D-12      │ │  D-83      │ │
│ │ 2026.09.01 │ │ 2026.11.30 │ │
│ └───────────┘ └───────────┘ │
│ (마감 임박 시 카드 배경 붉은색)  │
├─────────────────────────────┤
│ (선택) 알림 받을 연락처 입력     │
├─────────────────────────────┤
│ 하단 탭바: 홈 [D-day] 서류확인  │
└─────────────────────────────┘
```
- **구성요소**: 날짜 입력 필드, 계산 버튼, D-day 결과 카드 2개(색상: 평시 회색/파랑, 7일 이내 주황, 1일 이내 빨강), 알림 연락처 입력(선택, Should)
- **상태**: 미입력(안내 문구만 표시) / 계산 완료 / 마감 경과(경고 색상+안내 문구)
- **관련 기능**: FT-07, FT-08

---

### SC-04. 서류 자가진단
- **목적**: 부당처우 등 법정 사유 해당 가능성을 개인화해서 안내
- **레이아웃**
```
┌─────────────────────────────┐
│ 헤더(SC-00)                  │
├─────────────────────────────┤
│  계약서·통지서 사진을 올려주세요  │
│ ┌─────────────────────────┐ │
│ │   [카메라] [갤러리에서 선택]  │ │
│ └─────────────────────────┘ │
├─────────────────────────────┤
│ [업로드된 이미지 미리보기]       │
│ [분석하기 버튼]                │
├─────────────────────────────┤
│ 분석 결과                      │
│ "○○ 사유에 해당할 가능성이       │
│  있어 보입니다"                 │
│ [지원센터 상담 연결] [면책 배너]  │
└─────────────────────────────┘
```
- **구성요소**: 업로드 영역(카메라/갤러리), 미리보기, 분석 버튼, 결과 카드(가능성 안내+상담 연결 버튼+면책 배너)
- **상태**: 업로드 전 / 분석 중(로딩) / 결과 표시 / 판독 실패("직접 확인이 어려워요, 지원센터 상담을 권장합니다")
- **관련 기능**: FT-09, FT-10, FT-11

---

### SC-05. (Should) 관리자 — 검수 대기함
- **목적**: 신뢰도 낮은 AI 답변을 실무자가 확인 후 게시
- **레이아웃**
```
┌─────────────────────────────┐
│ 검수 대기 목록 (3건)           │
├─────────────────────────────┤
│ Q. 질문 내용                  │
│ AI 초안 답변 미리보기            │
│ [승인] [반려] [수정 후 게시]     │
├─────────────────────────────┤
│ ...                          │
└─────────────────────────────┘
```
- **구성요소**: 검수 대기 리스트, 각 항목별 승인/반려/수정 액션
- **관련 기능**: FT-06

---

## 5. 반응형·접근성 가이드

- 모바일 퍼스트: 375px 기준 설계, 태블릿/데스크톱은 콘텐츠 폭만 확장(1단 → 중앙 정렬 유지)
- 저사양 기기·저속 네트워크 고려: 이미지 최소화, 스켈레톤 로딩으로 체감 속도 개선
- 문해력이 낮은 사용자를 고려해 아이콘+짧은 텍스트 병행, 문장은 짧게
- 색상 대비: 마감 임박 경고색(주황/빨강)은 명도 대비 WCAG AA 기준 충족하도록 확인
- 다국어 텍스트 길이 차이(예: 태국어·베트남어는 한국어보다 길어짐)를 고려해 버튼/카드 텍스트 영역에 여유 확보
